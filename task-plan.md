### ✅ 1. Проектирование структуры OpenAPI спецификации

**Промпт:**
Сгенерируй базовую OpenAPI-спеку (`backend/api/openapi.yaml`) для MVP платформы недвижимости:

- Эндпоинты: `/projects`, `/units`, `/auth`, `/users`, `/appointments`, `/favorites`
- Методы: `GET`, `POST`, `DELETE`, `PUT` где применимо
- Типы: Project, Unit, User, Appointment, Favorite
- Язык спецификации: YAML
  Не включай реальные данные — только структуру.

---

### ✅ 2. Генерация серверного кода на Go по OpenAPI

**Промпт:**
Сгенерируй код на Go из `openapi.yaml`, используя `oapi-codegen`.

- Генерация в `backend/internal/generated/api.gen.go`
- Пакет: `generated`
- Типы: `types`, `fiber`
- Примени команду:

```bash
oapi-codegen -package generated -generate "types,fiber" -o backend/internal/generated/api.gen.go backend/api/openapi.yaml
```

### ✅ 3. Реализация хендлеров: получение списка проектов

**Промпт:**
Создай Go-хендлер `/projects` (`GET`), который возвращает мок-данные проектов.

- Расположи в `backend/internal/handlers/projects.go`
- Используй структуру из `generated`
- Верни slice из 2–3 объектов с полями: id, title, location, priceFrom, status
- Подключи в `cmd/server/main.go` через Fiber + RegisterHandlers
